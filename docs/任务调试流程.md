# 任务调试流程

以下命令假设在 ROS 2 Foxy 容器中运行，仓库位于 /workspace。

## 单独启动任务节点

task_launch.py 只启动任务执行器；运动控制、定位、感知等依赖节点需已由其他流程启动。单项 task YAML：

~~~~bash
ros2 launch uv_task task_launch.py mission_file:=/workspace/workspace_auv/src/uv_task/config/tasks/26rb_hit_balls.yaml
~~~~

启动 mission YAML：

~~~~bash
ros2 launch uv_task task_launch.py mission_file:=/workspace/workspace_auv/src/uv_task/config/missions/robocup_26.yaml
~~~~

## 通过 bringup 启动任务

bringup 会启动系统组件。将 enable_task 设为 true，并用 mission_file 选择要执行的 task 或 mission：

启动单项 task YAML：

~~~~bash
ros2 launch uv_sim_bringup sim.launch.py enable_task:=true mission_file:=/workspace/workspace_auv/src/uv_task/config/tasks/26rb_hit_balls.yaml
~~~~

启动 mission YAML：

~~~~bash
ros2 launch uv_sim_bringup sim.launch.py enable_task:=true mission_file:=/workspace/workspace_auv/src/uv_task/config/missions/robocup_26.yaml
~~~~

task YAML 描述一个任务及其参数；mission YAML 描述按顺序执行的任务列表。两种文件都传给 mission_file。params_file 只用于 ROS 参数 YAML，不能用来传 task 或 mission 文件。

## /auv/mission DDS 接口

| 名称 | DDS 类型 | 用途 |
|---|---|---|
| /auv/mission/run | Service：uv_msgs/srv/RunTask | 加载并启动 task/mission 配置；请求的 task_name 可填配置文件路径，start=false 请求停止任务列表。 |
| /auv/mission/stop | Service：std_srvs/srv/Trigger | 紧急停止当前任务和活动运动。 |
| /auv/mission/execute | Service：uv_msgs/srv/ExecTask | debug_mode=true 时单独执行一个已注册 task，参数通过 JSON 传入；用于调试单个动作，不是启动整份 mission。 |
| /auv/mission/status | Topic：uv_msgs/msg/TaskStatus | 发布任务状态、当前任务序号/名称、任务总数和错误信息。状态包括 idle、running、paused、done、error。 |

通过 DDS 服务启动一份配置的例子：

~~~~bash
ros2 service call /auv/mission/run uv_msgs/srv/RunTask "{task_name: '/workspace/workspace_auv/src/uv_task/config/missions/robocup_26.yaml', start: true}"
~~~~

旧接口 /task/run、/task/stop、/task/exec、/task/status 仍作为兼容别名；新命令使用 /auv/mission/...。
