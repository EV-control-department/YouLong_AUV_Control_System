# 目标物三维位置估计：观测与误差建模

## 1. 文档范围

本文保留三种观测形式的通用数学模型，但当前 `object_localizer` 的运行实现已切换为**只使用下视直接观测**。当前实现的主链路是：下视双目/平面交点 → 按物理类别的大型观测池 → 依据类别数量 K 的二维 N/E 聚类 → 每个簇最多 50 条下视观测的卡尔曼队列 → 静态目标位置输出。

历史模型中的三种观测形式为：

1. FRONT_STEREO：前视左右目在同一时刻对目标的双目观测；
2. FRONT_MULTI_VIEW：前视相机在不同机器人位置、不同时间对同一静态目标的多次观测；
3. DOWN_DIRECT：下视相机在当前时刻直接给出的目标位置观测，优先使用目标所在平面与相机射线求交，也允许使用下视单帧双目结果。

历史三种观测在几何一致时没有先后顺序；但当前实现不加载或订阅前视观测，只使用 `DOWN_DIRECT`。下视通常更准确，应通过更小的观测协方差体现；当某一次下视观测的平面、标定、姿态或检测质量较差时，仍然必须先通过几何质量检查，再由类别 K 聚类和卡尔曼窗口抑制其影响。

本文假设目标在任务期间静止，最终估计的是每个目标在 odom/NED 坐标系中的位置，而不是目标速度或运动轨迹。

相关节点总体设计见：[目标物静态三维位置估计节点设计](目标物三维位置估计节点设计.md)。新实现不使用旧的 uv_camera/position.py。

## 2. 符号和坐标约定

### 2.1 坐标系

| 符号 | 坐标系 | 轴定义 |
|---|---|---|
| W | odom/NED | x=North，y=East，z=Down |
| B | body/FRD | x=Forward，y=Right，z=Down |
| C | 相机光学坐标系 | x=Right，y=Down，z=Forward |
| C_r | 双目校正坐标系 | 由 R1/R2/P1/P2 定义 |

旋转矩阵 R_A_B 表示把 B 坐标系中的向量变换到 A 坐标系：

~~~
p_A = R_A_B p_B
~~~

机器人在观测时刻 t_k 的位姿记为：

~~~
t_WB,k = [x_k, y_k, z_k]ᵀ
R_WB,k = R_WB(roll_k, pitch_k, yaw_k)
~~~

相机外参记为：

~~~
t_BC = 相机光心在 body 中的位置
R_BC = camera_optical 到 body 的旋转
~~~

相机光心和目标点的转换为：

~~~
o_W,k = t_WB,k + R_WB,k t_BC
p_W   = t_WB,k + R_WB,k (t_BC + R_BC p_C)
~~~

所有目标状态和观测转换必须使用检测时间 t_k 对应的机器人位姿，不能使用回调时最新的一帧位姿代替历史位姿。

### 2.2 静态目标状态

对每个已经完成数据关联的目标实例 i，状态仅包含位置：

~~~
L_i = [x_i, y_i, z_i]ᵀ ∈ R³
~~~

其中 L_i 是目标在 W=odom/NED 中的位置。目标不设置速度状态：

~~~
L_i(t + Δt) = L_i(t)
~~~

如果使用 EKF，为了表达模型不完美、坐标系缓慢漂移或水下平台微小扰动，可以使用很小的随机游走噪声：

~~~
L⁻_k = L⁺_{k-1}
P⁻_k = P⁺_{k-1} + Q_static Δt
~~~

Q_static 是不确定性模型，不表示目标真的在运动。因子图方案不需要添加目标速度变量，可以直接对同一个 L_i 加入来自不同时间的观测因子。

### 2.3 观测点定义

检测消息通常给出边界框和置信度。第一版使用边界框中心：

~~~
u = (x_min + x_max) / 2
v = (y_min + y_max) / 2
~~~

但该点不一定等于几何中心。应为每类目标配置观测锚点：

| 目标形态 | 默认锚点 | 注意事项 |
|---|---|---|
| 球体 | 框中心，近似球心 | 需要考虑检测框中心偏移和球半径 |
| 门、框体、板 | 框中心或任务定义的中心点 | 不要把任意可见边缘当成目标位置 |
| 位于池底的标志物 | 与池底平面相交的目标基准点 | 明确该点是否就是控制需要的位置 |

如果检测网络输出的是 mask、关键点或目标中心，应优先使用其实际几何锚点，并为不同锚点配置不同的像素误差。

## 3. 相机投影和标定不确定性

### 3.1 标定 profile 的角色

实机/录包 profile 使用：

~~~
front.npz：前视左右目 K、D、R、T、R1、R2、P1、P2、Q
down.npz ：下视左右目 K、D、R、T、R1、R2、P1、P2、Q
~~~

这两个文件是实机标定 profile，应在实机节点启动时加载。它们不能只被 setup.py 打包而不参与运行，也不能用 common.py 中的近似内参或旧 position.py 的经验参数替代。

当前 down.npz 保持不修改，直接作为下视标定 profile 使用。产品规格图只用于确认硬件视场、分辨率和安装形式，不能用来推导或覆盖标定矩阵。

默认 Stonefish 仿真则使用单独的 `sim_camera_info` profile：节点订阅四个 `/sim/*/camera_info` 主题，直接使用仿真器渲染图像所发布的 K、D、分辨率；左右目相对外参由当前 `xunyun_fixed.scn` 相机 `<origin>` 计算，再以 `cv2.stereoRectify` 生成 `R1/R2/P1/P2/Q`。这样 `FRONT_STEREO`、`DOWN_DIRECT` 的双目部分以及 `FRONT_MULTI_VIEW` 的单目反投影，使用的是同一份实际仿真相机模型。

当前仿真为零畸变、1280×960：前视 `fx=fy=1174.086809, cx=640, cy=480`，下视 `fx=fy=672.183656, cx=640, cy=480`；两组左右目基线均为 `0.100 m`。它们与实物 `.npz` 的内参和 0.05653/0.07531 m 投影基线不同，因此仿真运行绝不能回退使用 `.npz`。

### 3.2 畸变和去畸变

对原始像素 z=[u,v]ᵀ，使用对应相机的 K、D 通过 OpenCV 畸变模型得到归一化射线：

~~~
q = undistortPoints(z, K, D)
d_C = normalize([q_x, q_y, 1]ᵀ)
~~~

双目观测必须使用左右目各自的 K_l、D_l 和 K_r、D_r。不能用左目参数处理右目像素，也不能在图像缩放后继续直接使用原分辨率的内参。

如果输入图像由标定分辨率 (W_0,H_0) 缩放到 (W,H)，应先按缩放比例更新内参：

~~~
s_x = W / W_0
s_y = H / H_0
K' = [[s_x fx,   0, s_x cx],
      [  0,   s_y fy, s_y cy],
      [  0,      0,      1  ]]
~~~

如果图像发生裁剪，还必须同时更新主点。输入分辨率、裁剪区域和标定分辨率不一致时，观测应进入 CALIBRATION_INVALID 或 CALIBRATION_MISMATCH，不能静默输出坐标。

### 3.3 像素检测误差

对一次检测，定义像素测量协方差：

~~~
Σ_pix = [[σ_u²,  ρ_uv σ_u σ_v],
         [ρ_uv σ_u σ_v, σ_v²]]
~~~

建议第一版令 ρ_uv=0，并根据检测框大小和置信度设定：

~~~
σ_u = clip(α_u · width_box,  σ_u_min, σ_u_max)
σ_v = clip(α_v · height_box, σ_v_min, σ_v_max)
s_c = clip(c_ref / max(confidence, c_min), 1, s_c_max)
Σ_pix ← s_c² Σ_pix
~~~

α_u、α_v、最小/最大像素误差需要由标注数据或录包统计标定。置信度只能作为噪声缩放因素，不能直接当作高斯概率，也不能把 confidence=1 解释为零误差。

### 3.4 位姿、外参和标定误差

令机器人位姿误差为：

~~~
δξ_pose = [δt_x, δt_y, δt_z, δθ_x, δθ_y, δθ_z]ᵀ
Σ_pose = cov(δξ_pose)
~~~

相机外参误差为：

~~~
δξ_extr = [δt_BC, δθ_BC]ᵀ
Σ_extr = cov(δξ_extr)
~~~

标定文件通常没有显式给出 Σ_calib，因此需要在 profile 中配置一个保守的标定误差，至少包含：焦距/主点误差、畸变参数误差、双目基线误差和左右目相对旋转误差。

对任意观测函数 h(L, ξ)，若把机器人位姿、外参和标定视为已知但不确定，则有效观测协方差采用一阶传播：

~~~
R_eff = R_pixel
      + J_pose  Σ_pose  J_poseᵀ
      + J_extr  Σ_extr  J_extrᵀ
      + J_calib Σ_calib J_calibᵀ
~~~

其中 J_* = ∂r/∂ξ_* 在当前估计点处计算。若位姿误差由同一个 odom 漂移项引起，则不同时间的观测之间存在相关性；简单 EKF 可以使用增大的等效噪声，因子图则应在条件允许时把位姿或漂移项作为共享变量建模。

## 4. 观测一：FRONT_STEREO

### 4.1 原始测量

同一时刻前视左右目分别检测到目标锚点：

~~~
z_fs,k = [u_l, v_l, u_r, v_r]ᵀ
~~~

左右目检测必须满足：

- 时间戳差小于 stereo_sync_slop；
- 类别相同且一对一匹配；
- 校正后极线误差小于阈值；
- 三角化结果为正深度；
- 左右目重投影误差小于阈值。

同一左右目像素如果已经进入 FRONT_STEREO 因子，就不能再把它作为一条独立 FRONT_MULTI_VIEW 单目因子重复加入，否则会重复计算同一份检测信息。

### 4.2 像素重投影模型

令 π_l、π_r 表示使用前视左右目标定和当前位姿的投影函数：

~~~
p_Cj,k = T_CjB T_BW,k L_i
h_fs,k(L_i) = [π_l(p_Cl,k), π_r(p_Cr,k)]ᵀ
r_fs,k = z_fs,k - h_fs,k(L_i)
~~~

这里 j∈{l,r}，投影函数包括：

1. odom/NED → body/FRD；
2. body/FRD → camera optical；
3. 相机畸变模型；
4. 相机内参投影。

使用原始像素重投影因子时，三角化点只用于初始化、数据关联和质量检查。这个建模方式不会因为先三角化再转坐标而丢失像素误差结构。

### 4.3 三角化和视差质量

在校正图像中，使用 P1/P2 对左右像素三角化：

~~~
X_h = triangulatePoints(P1, P2, z_l, z_r)
p_Cr = X_h[0:3] / X_h[3]
~~~

应检查三角化点在左右相机前方，并将结果重投影回左右图像：

~~~
e_reproj = max(
    ||z_l - project_l(X)||₂,
    ||z_r - project_r(X)||₂
)
~~~

对理想水平校正双目，深度近似为：

~~~
Z = f_x B / d
d = u_l - u_r       # 符号以当前 P1/P2 实际坐标系为准
~~~

视差误差为 σ_d² = σ_ul² + σ_ur²（若左右目误差独立），则：

~~~
σ_Z² ≈ (f_x B / d²)² σ_d²
~~~

还应加入焦距、基线和姿态误差的传播项：

~~~
σ_Z² ← σ_Z²
      + (B/d)² σ_fx²
      + (f_x/d)² σ_B²
      + J_pose,z Σ_pose J_pose,zᵀ
~~~

因此视差越小，深度方差越大。不能因为检测置信度较高就把远距离小视差结果当成高精度三维位置。

### 4.4 FRONT_STEREO 协方差

像素噪声矩阵为：

~~~
R_pix,fs = block_diag(Σ_pix,l, Σ_pix,r)
~~~

在残差空间中传播其他误差：

~~~
R_fs = R_pix,fs
      + J_pose  Σ_pose  J_poseᵀ
      + J_extr  Σ_extr  J_extrᵀ
      + J_calib Σ_calib J_calibᵀ
~~~

如果系统采用三角化后的等效位置观测：

~~~
z̄_fs = p_W,tri
r̄_fs = z̄_fs - L_i
R̄_fs = J_tri R_pix,fs J_triᵀ
      + J_pose Σ_pose J_poseᵀ
      + J_extr Σ_extr J_extrᵀ
      + J_calib Σ_calib J_calibᵀ
~~~

优先使用像素重投影模型；等效位置模型只用于无法直接建立重投影因子的实现或调试阶段。两者不能同时把同一像素信息作为独立观测使用。

## 5. 观测二：FRONT_MULTI_VIEW

### 5.1 观测含义

FRONT_MULTI_VIEW 是前视相机在不同机器人位置对同一静态目标的多次观测。它不是把多帧像素坐标平均，也不是要求某个固定的“先前视、后下视”流程，而是让多个时刻的观测共同约束一个静态状态 L_i。

第 k 次观测保存自己的时间戳和位姿：

~~~
z_mv,k = [u_k, v_k]ᵀ
t_k
T_WC,k
~~~

可以使用前视左目、右目中的一个作为单目射线，也可以在一个时刻使用已经校正的双目观测。但如果同一时刻已使用 FRONT_STEREO，不要再次把左右目像素作为无相关性的 FRONT_MULTI_VIEW 观测加入。

### 5.2 像素重投影模型

对于保存的每一个前视单目观测：

~~~
h_mv,k(L_i) = π_front(T_CW,k L_i)
r_mv,k = z_mv,k - h_mv,k(L_i)
~~~

多个时刻的残差拼接为：

~~~
r_mv(L_i) = [r_mv,1ᵀ, r_mv,2ᵀ, ..., r_mv,Nᵀ]ᵀ
~~~

它们都作用于同一个 L_i。机器人运动提供的是相机观测射线之间的夹角和基线，不是目标运动模型。

### 5.3 射线模型

在不能或不需要保留像素重投影时，将像素转成世界射线：

~~~
o_k = 相机光心在 W 中的位置
d_k = normalize(R_WC,k d_C,k)
~~~

点到射线的正交残差为：

~~~
A_k = I - d_k d_kᵀ
r_ray,k = A_k (L_i - o_k)
~~~

该残差只有两个独立约束，沿射线方向不提供距离信息。不能把 A_k(L_i-o_k) 当成三个相互独立的误差分量，否则会人为增加信息量。

多射线的加权最小二乘解可写为：

~~~
Λ = Σ_k A_kᵀ R_ray,k⁻¹ A_k
b = Σ_k A_kᵀ R_ray,k⁻¹ A_k o_k
L̂ = Λ⁻¹ b
P = Λ⁻¹
~~~

若 Λ 奇异或条件数过大，说明观测射线接近平行、运动基线不足或姿态不可靠，此时只能保留候选观测，不能发布高可信三维位置。

### 5.4 多位置几何质量

两条射线 d_a、d_b 的夹角为：

~~~
φ = acos(clip(d_aᵀ d_b, -1, 1))
~~~

当 sin(φ) 太小时，交会深度对像素和位姿误差非常敏感。质量指标至少包括：

- 最大/最小射线夹角；
- 机器人平移基线；
- 目标估计深度；
- 射线交会残差；
- 位姿时间差和时间同步误差；
- 多条射线联合信息矩阵的条件数；
- 同类目标的跨帧关联置信度。

多位置估计的协方差由联合信息矩阵得到，并加入位姿、外参和像素误差：

~~~
R_mv,k = R_pix,k
       + J_pose,k Σ_pose,k J_pose,kᵀ
       + J_extr,k Σ_extr J_extr,kᵀ
       + J_calib,k Σ_calib J_calib,kᵀ
~~~

对于同一个 odom 段内的多帧观测，Σ_pose,k 可能具有相关性。没有共享位姿变量的实现应通过增大噪声、限制有效帧数或按运动段降采样，避免把高相关帧当作大量独立证据。

## 6. 观测三：DOWN_DIRECT

### 6.1 直接观测的定义

DOWN_DIRECT 表示下视当前观测可以直接形成目标位置约束，不依赖前视历史，也不依赖机器人先完成一段特定运动。推荐按以下优先级建模：

1. 目标锚点位于已知池底/任务平面：使用单目像素射线与平面求交；
2. 目标锚点不适合用平面约束，但下视左右目可匹配：使用下视单帧双目三角化；
3. 只有单目像素而没有可靠平面、深度或尺寸约束：不能生成三维位置观测，只能发布二维方向候选。

下视平面求交和下视双目三角化都属于 DOWN_DIRECT，但必须在观测消息中记录 down_geometry_type，以便使用正确的协方差模型。

### 6.2 平面射线求交模型

用世界坐标系表示目标锚点所在平面：

~~~
Π: nᵀ p_W + c = 0
||n|| = 1
~~~

其中 n、c 和它们的不确定性由运行 profile 提供。对下视像素 z_d=[u,v]ᵀ：

~~~
d_C = undistort_and_normalize(z_d, K_down, D_down)
d_W = normalize(R_WC d_C)
o_W = camera_origin_in_W
λ = -(nᵀ o_W + c) / (nᵀ d_W)
p̂_d = o_W + λ d_W
~~~

必须检查：

- |nᵀd_W| 不接近零；
- λ > 0；
- 交点在任务区域内；
- 目标锚点到平面的定义正确；
- 下视图像没有超出标定有效区域。

为了避免在三维残差中重复加入平面已经提供的法向约束，建议使用平面切向基 B∈R^{3×2}，满足：

~~~
BᵀB = I
Bᵀn = 0
~~~

平面直接观测残差为：

~~~
r_down,plane = Bᵀ (p̂_d - L_i)
~~~

如果目标位置状态允许离开平面，另外增加软平面因子：

~~~
r_plane = nᵀ L_i + c
~~~

该因子的方差应由平面高度、法向和目标锚点误差决定，不能设置为零硬约束。

### 6.3 平面交点误差传播

平面交点是函数：

~~~
p̂_d = g(z_d, T_WC, Π)
~~~

令误差变量为：

~~~
η_d = [δu, δv, δξ_pose, δξ_extr, δn, δc]ᵀ
Σ_η = cov(η_d)
~~~

对切向残差进行一阶传播：

~~~
R_down,plane = J_η Σ_η J_ηᵀ
J_η = ∂r_down,plane / ∂η_d
~~~

等价地，可以拆开写为：

~~~
R_down,plane =
      J_pix   Σ_pix   J_pixᵀ
    + J_pose  Σ_pose  J_poseᵀ
    + J_extr  Σ_extr  J_extrᵀ
    + J_n     Σ_n     J_nᵀ
    + J_c     σ_c²    J_cᵀ
    + J_calib Σ_calib J_calibᵀ
~~~

下视相机接近平行于目标平面时，交点深度误差会迅速放大。即使下视通常较准，也必须根据 |nᵀd_W|、平面参数质量和像素位置动态增大协方差。

### 6.4 下视单帧双目模型

没有可靠平面约束时，可使用下视左右目原始像素：

~~~
z_down,stereo = [u_l, v_l, u_r, v_r]ᵀ
h_down,stereo(L_i) = [π_down,l(T_CW,l L_i),
                       π_down,r(T_CW,r L_i)]ᵀ
r_down,stereo = z_down,stereo - h_down,stereo(L_i)
~~~

协方差为：

~~~
R_down,stereo = R_pix,down
              + J_pose Σ_pose J_poseᵀ
              + J_extr Σ_extr J_extrᵀ
              + J_calib Σ_calib J_calibᵀ
~~~

down.npz 提供下视左右目的 K/D/R/T/R1/R2/P1/P2。下视双目必须检查校正、正深度、极线误差和重投影误差；不能仅根据“下视看到目标”就把深度设为准确值。

### 6.5 下视的质量不是无条件真值

下视常见的优势是目标距离更近、射线与池底平面交会角度更好、目标锚点更明确。因此通常：

~~~
trace(R_down) < trace(R_front)
~~~

但这只是 profile 和实际几何下的常见结果，不是融合规则。以下情况会使 R_down 变大甚至使观测无效：

- 下视标定文件与输入分辨率不匹配；
- 下视安装外参未标定；
- 池底/任务平面高度不确定；
- 目标实际不在假设平面上；
- 像素靠近畸变边缘；
- 射线与平面接近平行；
- 检测框中心不是目标锚点；
- 左右目匹配或重投影残差过大。

## 7. 统一的融合模型

### 7.1 因子图模型

对每个目标实例 i，因子图变量为：

~~~
L_i ∈ R³
~~~

每条观测根据 observation_form 产生自己的残差和协方差：

~~~
FRONT_STEREO     → r_fs,k(L_i),    R_fs,k
FRONT_MULTI_VIEW → r_mv,k(L_i),    R_mv,k
DOWN_DIRECT      → r_down,k(L_i),  R_down,k
~~~

总目标函数：

~~~
min_{L_i}  Σ_k ρ( r_k(L_i)ᵀ R_k⁻¹ r_k(L_i) )
~~~

ρ 建议使用 Huber；检测错配较多时可以使用 Cauchy 或带开关变量的鲁棒因子。R_k 由每次观测自己的检测框、视差、射线几何、机器人位姿和标定误差生成。

因子加入顺序不改变目标函数：

~~~
FRONT_STEREO → DOWN_DIRECT → FRONT_MULTI_VIEW
DOWN_DIRECT → FRONT_STEREO → FRONT_MULTI_VIEW
FRONT_MULTI_VIEW → DOWN_DIRECT → FRONT_STEREO
~~~

只要观测时间、姿态、标定和数据关联相同，排列顺序不应决定最终物理结果。滑动窗口只影响保留的历史范围，不改变三种观测的定义。

### 7.2 EKF 等价实现

资源受限时，对每个目标使用三维 EKF。预测：

~~~
x⁻ = x⁺
P⁻ = P⁺ + Q_static Δt
~~~

对某一观测模型 z=h(x)：

~~~
r = z - h(x⁻)
H = ∂h/∂x |_{x⁻}
S = H P⁻ Hᵀ + R
K = P⁻ Hᵀ S⁻¹
x⁺ = x⁻ + K r
P⁺ = (I-KH)P⁻(I-KH)ᵀ + K R Kᵀ
~~~

使用 Joseph 形式更新 P，保证数值上保持半正定。不同观测形式只替换 h/H/R，不能通过固定增益、EMA 或“下视直接覆盖”实现。

EKF 的更新顺序在非线性情况下可能带来轻微差异，因此建议：

- 对同一时间批次的观测先批量线性化；或
- 采用迭代 EKF；或
- 使用滑动窗口因子图作为主实现。

### 7.3 门控和鲁棒权重

对残差使用马氏距离门控：

~~~
d² = rᵀ S⁻¹ r
~~~

根据残差维数选择卡方阈值。通过门控后再使用 Huber 权重：

~~~
w(d) = 1,                    d ≤ δ
       δ / d,                d > δ
~~~

等效信息矩阵为：

~~~
Λ_eff = w(d) Hᵀ R⁻¹ H
~~~

对严重超限但没有足够证据判定为错误匹配的观测，保留为低权重候选；对明显不可能的正深度、极线、平面交点或坐标范围错误，直接拒绝。

### 7.4 不允许重复计算观测信息

以下信息相关，不能不加处理地重复加入：

- 一次 FRONT_STEREO 的左右目像素与由其三角化出的 XYZ 点；
- 一次 DOWN_DIRECT 的平面交点与由同一像素、同一平面重新生成的独立三维点；
- 同一时刻、同一相机检测在不同消息通道中重复发布的结果；
- 已包含左右目像素的双目观测再次拆成两条独立单目多视角观测。

如果确实需要同时使用，应显式建立联合协方差或只保留其中一种表示。

## 8. 数据关联和静态目标合并

当前下视观测按物理类别进入独立观测池，不能以左右目、时间帧或检测框序号作为目标 ID；关联必须在统一的 W=odom/NED 中进行。

### 8.1 关联输入

每次观测至少包含：

~~~
class_id
observation_form
stamp
point_or_ray_in_odom
measurement_covariance
confidence
quality_metrics
~~~

### 8.2 已有目标的预测门控

对已有目标 L_i、P_i，将观测转换为位置等效值 z̄_k 后，可使用：

~~~
ν_i = z̄_k - L_i
D_i² = ν_iᵀ (P_i + R̄_k)⁻¹ ν_i
~~~

D_i² 通过门限才允许成为候选关联。对于原始像素观测，更推荐把已有 L_i 投影到该相机并使用像素重投影马氏距离门控。

同类别多个目标必须使用全局一对一分配，不能只选择置信度最高的目标。若多个候选代价接近，观测应进入 tentative 状态，等待后续观测消歧。

### 8.2.1 当前下视观测池和实例间距

当前实现先把所有通过下视几何质量检查的观测按 `physical_class_name` 放入大型观测池，默认每类保留 2000 条。观测池只负责保留原始证据，不直接把不同物体平均成一个位置。

随后每条观测按以下规则送入实例。当前实现的身份判定只在静态场景的北东平面进行：

~~~
δ_NE = z_NE - L_NE
S_NE = P_NE + R_NE
D_NE² = δ_NEᵀ S_NE⁻¹ δ_NE
~~~

这里 `NE` 是 `odom/NED` 中的 `[North, East]` 两个分量。完整 XYZ 不能直接用于实例身份判定：双目匹配/视差异常时，点可能只在 `Down` 方向跳变，若把该跳变当作新目标，就会把同一目标发布成两个 `instance_id`。`Down` 分量并没有丢弃，而是和 N/E 一起进入该实例的 3D 卡尔曼窗口。

1. 取该物理类别的 K 值：门 K=4、引导线 K=6、其他类别 K=1；
2. 对池中全部观测只取 N/E 两维运行 K-means，得到不超过 K 个水平位置簇；Z/Down 不参与距离和簇数判断；
3. 将当前簇与已有实例做 N/E 最小代价一对一映射；旧实例满额不再拒绝新观测，未绑定观测会在下一次聚类中重新参与；
4. 引导线簇中心之间小于 0.5 m 时合并，防止观测抖动生成近邻重复 ID。

每个聚类簇绑定一个实例，并维护最多 50 条 `DOWN_DIRECT` 队列。聚类只使用 N/E，Z/Down 不参与簇数、簇中心距离或实例映射；确定簇后，簇内最近 50 条观测以完整 XYZ 测量进入该实例的 3D 卡尔曼窗口，窗口状态直接作为当前下视静态位置估计。池中观测即使暂时无法绑定到某个实例，也不会因实例上限被丢弃，而会在下一次 K 聚类时重新参与。队列满后先进先出，避免很早的偶发误检永久影响后续下视判断。节点每次发布前还会合并同一物理类别的近邻下视重复假设；引导线的合并半径为 0.5 m，其他类别默认为 0.25 m。

### 8.3 新目标初始化

当前初始化来源只有 `DOWN_DIRECT`：可靠的下视平面交点或下视双目点。

初始化时协方差直接使用下视观测的等效协方差；下视也不能跳过左右目一致性、深度、队列马氏门限和后续卡尔曼一致性检查。

## 9. 观测质量到协方差的具体规则

### 9.1 通用流程

每次观测生成协方差的统一流程：

~~~
检测框/关键点
    ↓
像素协方差 Σ_pix
    ↓
标定和几何计算
    ↓
观测函数 h 或等效位置 g
    ↓
传播 pose/extrinsic/calibration/plane 误差
    ↓
质量门控与噪声放大
    ↓
R_k
~~~

最终不得只给出一个 confidence，必须给出至少 3×3 的等效位置协方差，或给出与原始残差维数匹配的 R_k。

### 9.2 质量放大因子

可以将几何质量转换成有限范围内的噪声放大因子：

~~~
s_quality = clip(
    s_conf · s_reprojection · s_geometry · s_pose,
    1,
    s_quality_max
)
R_k ← s_quality² R_k
~~~

建议：

- s_conf 来自检测置信度；
- s_reprojection 随极线/重投影残差增大；
- s_geometry 对小视差、小射线夹角和小平面交会角增大；
- s_pose 对位姿年龄、姿态协方差和 odom 漂移增大。

放大因子只能在物理协方差基础上调节，不能代替完整的误差传播。

### 9.3 观测形式之间的预期关系

初始 profile 可以有以下相对关系，但最终值必须通过数据验证：

~~~
FRONT_STEREO：视差主导，远距离时深度方差大
FRONT_MULTI_VIEW：运动基线主导，位姿和关联错误影响大
DOWN_DIRECT：平面/近距离几何通常更好，但对外参与平面误差敏感
~~~

不能直接设置一个固定规则，例如：

~~~
if source == DOWN:
    position = down_position
~~~

正确方式是让每条观测以自己的 R_k 进入同一融合器，并由残差门控和鲁棒权重处理冲突。

## 10. 推荐的观测记录结构

为了使融合结果可解释，每条观测至少记录：

~~~
TargetObservation:
  class_id
  temporary_track_id
  associated_instance_id
  observation_form              # FRONT_STEREO / FRONT_MULTI_VIEW / DOWN_DIRECT
  down_geometry_type            # PLANE_INTERSECTION / DOWN_STEREO，可选
  stamp
  pose_stamp_used
  pixel_measurement
  camera_profile                # FRONT / DOWN
  point_odom                    # 若已经生成等效三维点
  covariance                    # 原始残差或等效位置协方差
  confidence
  epipolar_error_px
  reprojection_error_px
  disparity_px
  ray_angle_deg
  plane_incidence
  pose_age_ms
  association_mahalanobis
  accepted / rejected / robust_weight
~~~

最终位置输出应称为 TargetPosition 或 TargetPositionArray，因为它表示当前静态目标位置估计；TargetTrack 只适合表示带运动轨迹或时序跟踪状态的接口。若保留 track 名称，也必须在消息注释中明确其状态是静态位置估计。

## 11. 实现和验证顺序

### 11.1 先验证几何，不先调融合

1. 加载 front.npz/down.npz，打印矩阵形状、单位和基线；
2. 检查输入分辨率、裁剪和缩放；
3. 使用已知左右目点验证正深度和重投影；
4. 验证 camera_optical → body/FRD → odom/NED 的轴向和符号；
5. 验证检测时间对应的位姿插值；
6. 再验证三种观测形式各自的残差和协方差。

### 11.2 单项模型测试

| 测试 | 预期 |
|---|---|
| 固定机器人、改变下视像素 | 平面交点方向正确，接近平行时方差增大 |
| 扰动 roll/pitch/yaw | 目标 odom/NED 坐标变化方向正确 |
| 下视观测重复输入 | 进入对应类别池和对应实例的 50 条卡尔曼队列 |
| 下视观测在不同类别之间交替输入 | 按 `physical_class_name` 分池，不串类 |
| 引导线近距离重复输入 | 不创建小于 0.5 m 的第二实例 |
| 注入错误匹配 | 马氏门控/鲁棒核抑制错误观测 |
| 删除或损坏 npz | 节点报告标定无效，不发布有效位置 |

### 11.3 验收指标

至少统计：

- 三维位置误差和各轴误差；
- 输出协方差是否覆盖实际误差；
- 下视观测池和每个实例队列的长度；
- 下视单点与 50 点卡尔曼队列输出的误差；
- 错误关联下的位置最大偏移；
- 位姿时间延迟对结果的影响；
- 小视差、小基线、小入射角时的拒绝率和协方差增长。

## 12. 必须遵守的建模结论

1. 状态是静态目标位置 L_i∈R³，不是目标速度状态。
2. 当前 `object_localizer` 只接受 `DOWN_DIRECT`，前视消息不订阅、不处理。
3. 下视观测先按物理类别进入大型观测池，再按空间规则分配到实例。
4. 每个实例使用独立的 50 条下视卡尔曼队列，不能把不同实例的观测混在一起。
5. 观测误差必须包含像素、机器人位姿、相机外参、标定以及下视平面误差。
6. 下视仍需通过左右目/平面质量检查；通过后先进入类别观测池，再按已知数量 K 做二维 N/E 聚类，簇内观测以 `R_down` 进入实例卡尔曼滤波。
7. 同一份左右目像素不能同时作为双目因子和独立多视角因子重复使用。
8. 当前 object_localizer 只加载/使用下视标定：实机使用 `down.npz`，仿真使用下视 CameraInfo；前视标定和前视检测不进入该节点。原有 uv_camera AI 节点仍有独立的图像预处理参数，不能把它们误认为定位节点的标定来源。
