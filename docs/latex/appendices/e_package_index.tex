\section{索引维护规则}
包索引只记录入口和职责，不复制所有类名。新增包时必须同时补充 package.xml、launch/entry point、依赖方向、接口契约、测试入口和本附录；删除或合并包时保留迁移说明，避免读者根据旧文档启动错误入口。
