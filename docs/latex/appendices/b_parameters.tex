\section{参数审查原则}
参数名称应包含物理含义，时间用秒、距离用米、角度明确度或弧度；速度和推力参数要说明坐标系和正方向；随机退化参数必须说明 seed；真机安全参数必须有更保守的 profile。完整生效树通过 ROS 2 参数查询和启动日志确认。
