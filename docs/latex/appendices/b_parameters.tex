  \item 相机内参与 real/sim 模式：\pathref{workspace_auv/src/uv_camera/stereos/}。

  \item 任务 Mission：\pathref{workspace_auv/src/uv_task/config/missions/}。
  \item 任务 Task：\pathref{workspace_auv/src/uv_task/config/tasks/}。
  \item 退化参数：\path{uv_sim_bringup/degradation.launch.py} 及 sim launch 参数。
  \item 真机整机启动 profile：\pathref{workspace_auv/src/uv_bringup/config/profiles/real/}。
  \item 仿真/HIL 整机启动 profile：\pathref{workspace_sim/src/uv_sim_bringup/config/profiles/}。
\end{itemize}

整机 \code{profile} 只由 bringup 入口解释，控制节点启停、录制等 launch 参数默认值；它不是 ROS 2 节点参数文件。组件默认参数由所属包维护，只有需要覆盖时才通过 \code{params\_file} 显式提供参数 YAML。相机标定 YAML 内的 \code{modes} 是 real/sim 相机数据分组，仿真场景则由 \code{uv\_sim} 的 \code{world} 选择。

\section{参数审查原则}
参数名称应包含物理含义，时间用秒、距离用米、角度明确度或弧度；速度和推力参数要说明坐标系和正方向；随机退化参数必须说明 seed；真机安全参数应有明确的默认值和评审记录。完整生效树通过 ROS 2 参数查询和启动日志确认。
