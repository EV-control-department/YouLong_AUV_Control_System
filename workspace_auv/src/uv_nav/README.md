# uv_nav（已弃用）

弃用日期：2026-09-26。

uv_nav 不再作为新的公开依赖或集成入口。新代码应依赖 uv_planning。

## 仍保留的用途

当前 uv_planning 的 launch 仍启动本包的 navigator executable，所以此包暂时保留，不能直接从工作区删除或停用。它是迁移中的 A* 后端，不是独立的规划 API 边界。

## 当前能力边界

节点订阅状态和感知障碍物，使用 A* 计算下一航点，并发布 WaypointPath。它没有跟随路径或驱动 BasicMotion 的执行闭环；当前导航服务也可能在规划器找不到路径时仍返回成功。因此，节点启动或服务成功不能视为导航任务已经完成。

## 迁移方向

后续将规划实现和稳定接口收敛到 uv_planning（或其明确拥有的内部实现），由规划/控制接口定义路径跟随责任。确认没有外部工作区直接依赖 uv_nav 后，再移除本包及兼容 executable。
