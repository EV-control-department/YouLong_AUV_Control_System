# 前视逐门过门任务

直接订阅 `/auv/perception/detections` 中 `front_left` / `front_right` 的
`gate_front`，使用单目标定、相机 TF 和实测 odom。没有有效实测定位时终止，
不会使用任务执行器的指令位姿代替定位。角度使用度，z 正向向下。

## 每门执行顺序

1. 从实测 yaw 将到 odom 绝对观测点的位移转换为 BTRAVEL 机体系增量，
   然后 SET 配置的完整 `[x,y,z,yaw]`。到位不闪灯。
2. 保持配置深度观察 2s，持续黄灯，按连续三帧 bbox 高度中位数选择最高的稳定候选。
   找到闪绿灯一次；没有则闪红灯一次。
3. 没找到时持续黄灯完成右扫 90° → SET 返回观测点和航向 → 左扫 90°，均为 10°/s。
   无论扫描中何时看到门框，都完成整段扫描；按扫描中最大稳定门框记录 yaw，
   扫描结束后转向该 yaw，并在 10s 内重新确认同一目标。没有候选闪红灯两次并失败。
4. 单目航向对准 → 再观察并记录固定水平射线 → 沿射线正向 BLINE 校准
   → 最终 yaw 稳定检查 → 新帧检查 → BLINE 穿门。
   闪灯先灭再亮，0.3s 亮、0.3s 间隔。

## 配置

`config/tasks/26rb_gate_task.yaml` 当前配置一个门：

```yaml
gate_count: 1
timeout: 720.0           # 每门总时限，包含导航、搜索、伺服和穿越
max_failures: 1         # 允许失败后跳到下一门的次数
observation:
  poses: [[1.5, -2.0, 0.2, 0.0]]  # odom 绝对 [x,y,z,yaw]
  travel_timeout: 60.0
  set_timeout: 20.0
fore_aft:
  height_limit_percent: 75.0
  speed_mps: 0.15
  max_distance_m: 0.50
```

`poses` 长度必须等于 `gate_count`（1–4）；新增门须填写真实观测位姿。
每个 pose 的 z 是该门搜索、对正和穿越全过程的巡游深度。
`depth` 配置垂向增益、限速和容限；旧 `depth.front` 若显式配置且与 pose z 冲突，
启动时报错。过门流程不再包含左右横向对正阶段。

高度百分比 = **裁剪后的 bbox 高度 / 所属单目画面高度 × 100**。
看到门框并对准后，沿记录的水平射线以 0.15m/s 单次 BLINE 向前最多 0.50m。
BLINE 行进中框高严格超过 75% 时会取消并确认停止，随后进入最终 yaw 对准和穿门阶段；
未超过阈值则走完整个 0.50m 后进入该阶段；
框宽度不参与该判断。近距校准阶段超时为 30s，单段到点容差为 0.01m。
旧的高度比例闭环和横向位置修正不再用于该阶段。新搜索使用 `search.scan_angle_deg` 和 `tracking` 参数。

## 固定目标身份

搜索维护所有候选轨迹，选择后固定目标 ID，伺服时不重新选最高/最大的框。
跟踪状态为去畸变中心、对数宽高和变化速度，采用 α=0.6、β=0.2 的预测更新，
结合实测姿态和相机外参补偿旋转；有验证通过的双目中心时补偿平移。
使用现有 Hungarian 一对一匹配，成本为中心 0.4、高度 0.3、IoU 0.2、宽高比 0.1。

`tracking` 默认连续确认 3 帧、归一化中心距离 0.12、最大高度/宽高比变化 1.5 倍、
歧义成本差 0.15。两个相似候选或两条竞争轨迹产生歧义时拒绝匹配，
立即停止世界水平运动并保持深度。边缘裁剪不用于收缩不可见的完整框边缘。

丢框保留目标 ID，10s 内只重捕获原轨迹；超过 2s 释放相机优先权，
但不会释放目标身份。左右目交接需要方向、尺度、连续三帧及可用双目几何检查。
双目按 pair ID／时间戳配对，并检查夹角、前向距离、射线间距和框高度一致性。
新门清空历史，导航期间不接受候选，到观测点后只接收该阶段的新鲜帧。

## 穿越与失败处理

最终 yaw 最少 1s，误差在 2° 内连续稳定 0.3s；最多 3s，未达标则失败。
近距校准结束后，最终 yaw 稳定达标并取得同一目标的新帧，才发送穿门 BLINE。
丢框、最终 yaw 对准失败、动作通信失败或单门总超时仍按原失败逻辑处理。
BTRAVEL/SET 到达预定位置和 BLINE 过门均不亮灯。BLINE 前先确认零速度；
穿越速度 0.2m/s，动作超时 20s；穿越和成功后 0.5s 停顿期间
不发送旧伺服速度。默认 BLINE 1.6m、0.2m/s、20s，使用 `final_target` 同步位姿。

单门失败先确认取消结果、零速度和停车，使用独立的有限清理预算。
取消响应本身不算动作终止；迟到的接受响应也会取消。无法确认时禁止进入下一门。
默认第一次失败可跳过，第二次失败或最后一门失败返回任务失败。
取消请求、无有效定位直接终止。成功消息记录通过和跳过数量。
