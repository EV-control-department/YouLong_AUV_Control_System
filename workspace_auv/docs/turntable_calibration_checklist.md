## 四、按顺序进行的放行试验

- [ ] 模型和两个类别 ID 正确；黄标角、盘心、采集时间持续有效，静止角度噪声已测。
- [ ] 盘轴心、法向、棍端、内外圈、孔位和黄标相位完成测量，并由第二人复核坐标与符号。
- [ ] 保持两个禁动开关为 `false`，只查看任务给出的预插入位姿；确认该位姿不会撞池壁、盘架或机器人本体。
- [ ] 在脱离转盘的位置，完成空载 `WTRAVEL`、小步插入/退出方向和 yaw 摆动测试；记录棍端轨迹、最大速度、过冲。
- [ ] 明确人工急停与故障退杆流程，确认控制器实际具备低速/限推力能力。
- [ ] 人工监护下，从**单个最小接触行程**试起，记录黄标转角、盘轴实际位移、是否碰辐条及是否把盘拉走；验证“完全退出再复位”。
- [ ] 再验证三次重复的同向性和一致性；目标规则明确后增加绝对角度/累计角度的闭环完成判据。
